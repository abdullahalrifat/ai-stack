# v0.9 real workload calibration

The runtime calibration layer is deliberately conservative. It stores model/task observations, applies a 30-day recency half-life, requires multiple samples, rejects routes below the quality floor, and scores correctness, tool failures, latency and estimated cost.

Jarvis owns workload generation and task-level evaluation. AI Stack owns execution telemetry and route selection. jarvis-core remains provider-neutral.
